王之宝库 · Bangumi 导入助手 v4.2
适配网站：https://hhd886.github.io/anime-watchlist/editor.html

一、已有旧插件：怎样升级（Chrome / Edge）
1. 先导入旧队列里的作品，避免更换插件目录后找不到旧队列。
2. 解压新版 Bangumi-Importer-v4.2.zip。
3. 把解压目录里的文件，复制覆盖到之前“加载已解压的扩展程序”使用的插件目录。
   请保持原来的目录位置；这样 Chrome / Edge 会继续使用同一扩展，原队列也会保留。
   目录仍叫 Bangumi-Watchlist-Importer-v2 是为了兼容旧安装路径，实际版本已是 4.2.0。
4. 打开 chrome://extensions（Edge 是 edge://extensions），开启右上角“开发者模式”。
5. 找到这个插件，点击卡片上的圆形“重新加载”按钮，确认版本为 4.2.0。
6. 刷新已打开的 Bangumi 网页和王之宝库网页。
   网站更新不会自动更新“已解压加载”的浏览器扩展，升级插件需要做这一步。

二、第一次安装 / 找不到原目录
1. 把 ZIP 解压到固定目录，不要直接在压缩包里运行，也不要安装后移动目录。
2. 在浏览器扩展管理页开启开发者模式，点“加载已解压的扩展程序”。
3. 选择里面包含 manifest.json 的 Bangumi-Watchlist-Importer-v2 目录。
4. 若旧插件仍在，请停用旧插件，避免显示两个导入面板。
5. 使用 GitHub 网站不需要“允许访问文件网址”；只有使用本地 editor.html 才需要开启。

三、单部作品
在 bgm.tv / bangumi.tv / chii.in 条目页右下角：
- 收藏位置：仅存作品库 / 加入追番追更。
- 观看状态：想看、在看、已完成、搁置、放弃；完成的作品只进作品库。
- 类型：自动识别或手动选动画、漫画、小说。
- 待看区域、更新星期和 SSR/SR/R 优先级可调整。
- 可追加个人标签；展开“当前作品评分 / 评语”，可填写 9.9 等小数评分。
点“加入当前作品”，资料先保存到插件待导入队列。
评分与评语只用于当前作品，不会批量套用到其他条目。

四、一次导入本页多个作品
在 Bangumi 搜索结果、排行榜或收藏列表：
1. 点“选择本页作品…”。
2. 全选或勾选需要的作品（单页最多 500 部）。
3. 点“将选中作品加入队列”。成功的条目会边读取边保存。
4. 可以停止读取并重试失败项，不需要重新处理已成功的作品。

五、把队列带进网站
1. 打开王之宝库编辑页，点左侧“导入作品 → Bangumi 插件”。
2. 点“读取插件队列”，核对类型与勾选。
3. 保持默认“只补全空白资料”可以保护已有评分、评语、进度和收藏位置。
4. 点“导入选中作品”，再点网站右上角“发布”同步到 GitHub。
   网站确认保存成功后，插件才会移除这些已处理的队列记录。
备用方法：插件面板或浏览器扩展图标 → 导出队列 JSON；在网站“JSON 备份”导入。

六、上千部作品
直接在网站“导入作品”中使用：
- “批量链接 / ID”：一次最多 2000 部，两个请求并行，支持暂停、恢复上次任务和失败重试。
- “整批导入收藏”：填 Bangumi 用户名或个人主页链接，自动读取所有分页，最多 10000 部。
  可选择动画 / 漫画小说及收藏状态；看过的作品自动只放作品库。
- 导入预览每页 100 部，“全选全部”跨页生效，也可“只选新作品”。
- 预览下方可统一设置收藏位置、完成状态、更新区域、星期、优先级和个人标签。

权限与范围
仅在三个 Bangumi 域名、指定的王之宝库网站和用户允许的本地 HTML 上运行。
仅通过 Bangumi 公开 API 读取条目；不会修改 Bangumi 账号收藏。
不收集账号密码、GitHub Token，不自动发布网站。
手机 / iPad 无需安装桌面浏览器插件，可直接使用网站的批量链接或收藏导入。
