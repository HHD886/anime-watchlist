王之宝库 Bangumi 导入助手 v4.5.0

更新：把本文件夹内文件覆盖到原插件目录；在 chrome://extensions 或 edge://extensions 点击此扩展的重新加载；刷新 Bangumi 和作品库页面。保留原扩展 ID 才能保留旧队列，不要先卸载。
首次安装：开发者模式 → 加载已解压的扩展程序 → 选择有 manifest.json 的本目录。

1. 打开并解锁 https://hhd886.github.io/anime-watchlist/editor.html。
2. Bangumi 标题旁会显示已入库、同系列未入库、添加、待同步或无法确定。
3. 点击添加后先存队列；作品库保存成功后才显示已入库。已有 Subject ID 不会重复创建。
4. 右下角面板可筛选全部 / 未入库 / 同系列未入库 / 已入库，也能选择本页作品批量提交。
5. 插件图标里查看最后同步时间、重试队列或导出 JSON。编辑器关闭也不会丢请求，下次打开后继续。
6. 网站中修改完，点发布才会同步到 GitHub 和其他设备。

本地文件：扩展详情开启“允许访问文件网址”；插件弹窗展开地址设置，填入完整 file://…/editor.html 路径，保存并刷新该页面。默认绑定网站编辑器。

索引只包含必要 ID、标题和系列信息，不含作品库私人备注、评语、评分或 Token。页面状态在离线 / 索引过期时显示无法确定。实际关联不足时留待确认，不以标题相似强行合并。
完整说明位于仓库 UPGRADE-v4.5.md。
