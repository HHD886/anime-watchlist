Bangumi 追番表手动分类版 v2
================================

本版新增：
1. 每日更新区每一天都分为 SSR、SR、R。
2. 每日更新作品卡片有“完结”按钮，可直接移入完结待看区，并保留原优先级。
3. Bangumi 插件不再自动判断每日更新或完结待看。
4. 导入前由你手动选择：导入区域、更新星期、优先级。
5. 兼容旧版导出的 JSON 数据；导入后，旧版每日更新作品会保留原星期并默认进入 R。

安装或更新插件：
1. 解压本压缩包。
2. Chrome 输入 chrome://extensions/；Edge 输入 edge://extensions/。
3. 开启“开发者模式”。
4. 若安装过旧插件，建议先删除旧插件，避免两个面板同时出现。
5. 点击“加载未打包的扩展程序/加载解压缩的扩展”。
6. 选择 Bangumi-Watchlist-Importer-v2 文件夹（里面直接有 manifest.json）。
7. 进入插件详情，开启“允许访问文件网址”。
8. 刷新 Bangumi 页面和追番表 HTML。

导入一部作品：
1. 打开 Bangumi 条目页。
2. 在右下角选择“导入区域”。动画可选每日更新或完结待看；书籍可选漫画或小说。
3. 选择 SSR、SR、R。若选择每日更新，再选择周一至周日。
4. 点击“导入当前条目”。
5. 打开 editor.html。
6. 进入“导入作品 → 原版导入插件”，点击“读取插件队列”，勾选并确认导入。

作品完结后的移动方法：
在每日更新作品卡片右上角点击“完结”，确认后会进入完结待看区，并保持原来的 SSR、SR 或 R。

注意：
- 插件只提取封面、标题、标签、总数等资料；分类完全以你在面板中的选择为准。
- 批量导入会把本页所有识别出的作品统一放到当前选择的区域、星期和优先级。
- 数据仍保存在浏览器本地，请定期使用“导出数据”备份。

旧版数据迁移：
如果旧追番表中已经有正式数据，请先在旧页面点击“导出数据”，再在新版页面点击“导入数据”。不同文件地址下的浏览器本地存储不一定互通，因此不要只依赖自动读取。
