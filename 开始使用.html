留一页，给喜欢的故事。

把动画、漫画、小说与追番表放在一起。看到封面，就想起当时的喜欢。

打开在线作品库 → 本地编辑器

先带上旧记录

  1. 新版保留原网站的全部 33 条记录、封面、标签和进度，没有预设个人评分。
  2. 本地打开时，先导入同目录的 data.json；旧电脑若有尚未发布记录，请先在旧表导出 JSON。
  3. 新版点“导入作品 → 旧表 / JSON 备份”，选择文件、勾选条目，再确认导入。

继续用你原来的 GitHub 网站

  1. 进入“设置与备份”，仓库已预填为 HHD886/anime-watchlist，只需填写你自己的 GitHub Token。
  2. 原仓库有更新记录时，先“读取 GitHub”。
  3. 点“发布到 GitHub”，等待 Pages 构建完成，手机刷新原网址。
想只给自己看？在发布设置开启“加密发布作品数据”。本机编辑与普通备份仍是明文，修改后使用网页里的发布按钮同步。

你的日常使用

点封面评分、写评语；到个人榜单比较作品；到追番追更记录进度。修改先保存在本机，发布后其他设备才能看到。记得定期导出备份。
