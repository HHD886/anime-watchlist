# anime-watchlist

王之宝库 · HHD 的动画、漫画、小说收藏室。

[打开作品库](https://hhd886.github.io/anime-watchlist/) · [进入编辑](https://hhd886.github.io/anime-watchlist/editor.html) · [完整中文说明](README_CN.txt)

- 封面作品库，动画 / 漫画 / 小说分类，多标签组合筛选与搜索。
- 0.0–10.0 个人评分，精确到 0.1；排行榜、并列名次、分数分区。
- 每部作品有长评、带日期的随手记、评分历史和系列关联。
- 原追番表的星期、SSR / SR / R 优先级、完结待看和阅读进度；支持移出待看但保留作品。
- Bangumi 名称 / 条目链接 / 账号收藏导入，支持旧版 JSON。
- 本机自动保存、JSON 备份、GitHub Pages 发布、跨设备读取、可选加密。

功能升级保留现有作品记录与个人评分。修改先保存在当前设备，点击发布后其他设备才会看到。首次发布请在“设置与备份”填写自己的 GitHub Token，并先读取 GitHub。Token 不随网页或数据发布。

GitHub Pages 是公开网站；希望作品内容需要口令才能查看，可启用“加密发布作品数据”。加密不会清理以前的 Git 历史。本机编辑缓存和普通备份仍是明文。

下载整个仓库后也能双击 `editor.html` 本地使用；第一次在“导入作品 → JSON 备份”导入同目录的 `data.json`。具体步骤见 [开始使用](开始使用.html)。

## 开发与验证

不依赖 npm 包或 CDN 脚本。Node 18+：

```sh
node build.mjs
node --test src/core.test.cjs
```

重建保留现有 `data.json`，两个网页的内置作品数组均为空。`node build.mjs --standalone` 仅供制作含当前明文记录的本地编辑包，不应用于加密网站。

制作验证范围和限制见 [验证说明](验证说明.txt)。

## v4.3 年份与作品识别

心头好改为较小的淡黄色星星。导入预览中的作品名称可在新标签页打开对应 Bangumi 条目。

每部作品的第一个标签为四位年份；不再重复展示年月日标签。年份优先读取手填年份、条目日期，再兼容旧插件导入备注中的日期；无法识别时显示“年份待补”。筛选窗口将“年份”与“作品标签”分组，多选年份满足任意一个，再与其他筛选条件组合。作品库和榜单新增“年份从新到旧”，未知年份置后，榜单序号仍表示个人评分名次。

现有 v4.2 Bangumi 插件仍可使用，无需重新安装。

## v4.4 系列合集与原作关联

- 作品库默认按系列收起，同一合集只占一个格子；取消“按系列收起”可查看全部单独作品。动画、漫画、小说可放入同一个合集，展开后按媒体分区。
- 进入“作品库 → 整理系列”，填写系列名称并勾选成员。可选择合集封面，并为每部作品设置季度、OVA、OAD、剧场版、番外、篇章、上下部、MV、原作或改编等类型、自定义版本名和顺序。搜索后的勾选会保留；一次显示前 100 部，可用搜索缩小范围。
- “按名称批量整理”列出相近名称的建议；核对、勾选后才保存，不会自动改动整库。也可以在作品详情点“加入系列”。
- “查找 Bangumi 关联”读取条目的直接关联供选择，支持把已有条目放入合集，以及导入尚未收录的动画、漫画和小说。可点击名称查看 Bangumi；原作和改编作品会一起列出。新导入条目默认仅存作品库。关联名单并非全系列完整目录，缺失条目可手动添加。
- 已入库部分的季度数、其他版本数和书籍数分别显示；每部作品的评分、评语、随手记、进度、年份和追番状态独立保留。排行榜继续按单部作品评分，追番表继续按各部的进度显示。
- 合集封面上的“最高”指当前筛选命中的子作品最高个人分；年份为命中子作品的最新年份。筛选先匹配单部作品，再收起合集，因此搜到某一季也能打开完整合集。
- 修改系列名、移出成员或解散合集不会删除作品；整理操作有撤销及操作前备份。系列资料随 JSON / 加密备份与 GitHub 发布同步。
- 普通导入预览也可填写“归入同一系列”；补全模式仍保护已有作品的系列设置与个人记录。现有 v4.2 导入插件可继续使用。

保存整理后，点右上角“发布”，其他设备刷新即可看到相同的系列合集。
