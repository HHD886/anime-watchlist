# anime-watchlist

王之宝库 · HHD 的动画、漫画、小说收藏室。

[打开作品库](https://hhd886.github.io/anime-watchlist/) · [进入编辑](https://hhd886.github.io/anime-watchlist/editor.html) · [完整中文说明](README_CN.txt)

- 封面作品库，动画 / 漫画 / 小说分类，多标签组合筛选与搜索。
- 0.0–10.0 个人评分，精确到 0.1；排行榜、并列名次、分数分区。
- 每部作品有长评、带日期的随手记、评分历史和系列关联。
- 原追番表的星期、SSR / SR / R 优先级、完结待看和阅读进度；支持移出待看但保留作品。
- Bangumi 名称 / 条目链接 / 账号收藏导入，支持旧版 JSON。
- 本机自动保存、JSON 备份、GitHub Pages 发布、跨设备读取、可选加密。

本次升级保留原网站的全部 33 条记录；没有预设个人评分。修改先保存在当前设备，点击发布后其他设备才会看到。首次发布请在“设置与备份”填写自己的 GitHub Token，并先读取 GitHub。Token 不随网页或数据发布。

GitHub Pages 是公开网站；希望作品内容需要口令才能查看，可启用“加密发布作品数据”。加密不会清理以前的 Git 历史。本机编辑缓存和普通备份仍是明文。

下载整个仓库后也能双击 `editor.html` 本地使用；第一次在“导入作品 → JSON 备份”导入同目录的 `data.json`。具体步骤见 [开始使用](开始使用.html)。

## 开发与验证

不依赖 npm 包或 CDN 脚本。Node 18+：

```sh
node build.mjs
node --test src/core.test.cjs
```

重建保留现有 `data.json`，两个网页的内置作品数组均为空。`node build.mjs --standalone` 仅供制作含当前明文记录的本地编辑包，不应用于加密网站。

制作验证范围和限制见 [验证说明](验证说明.txt)。

## v4.1 交互更新

导航依次为追番追更、个人榜单、作品库。标签筛选整合到作品库与榜单搜索旁，支持多选与全部 / 任意匹配。评分分区细分到半分附近，最高两档按 9.6–10.0 与 9.0–9.5 划分。

作品详情与待看卡片支持标记完成、移出待看；添加 / 编辑时可选择仅存作品库。顶部刷新按钮读取 GitHub；存在未发布修改时先选择合并或替换。设置使用齿轮图标，网站标志已替换为用户提供的图片。

本次更新基于 32 条最新线上记录，部署不改动 data.json。

## v4.2 中文输入与批量导入

- 中文组合输入时保留搜索框节点，仅刷新结果区，兼容作品库与个人榜单。
- 独立的批量链接 / ID 导入：最多 2000 部，限并发 2，自动去重、暂停续读、失败重试。
- 账号收藏自动分页：可选择媒体 / 收藏状态；完成作品只放作品库。
- 预览每页 100 部，跨页全选、只选新作品、批量收藏位置 / 状态 / 标签。
- [下载导入助手 v4.2](Bangumi-Importer-v4.2.zip)：适配 GitHub 网站与本地 HTML。支持单部、小数评分、评语、标签及本页多选。
- 插件历史目录名保留为 `Bangumi-Watchlist-Importer-v2`，便于覆盖原目录升级和保留旧队列。
- 更新已解压的插件后，需在 Chrome / Edge 扩展管理页手动重新加载一次。

开发：`node build.mjs` 会同时更新插件共享核心，保持作品字段一致。
